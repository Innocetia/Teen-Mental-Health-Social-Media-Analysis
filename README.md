# Teen-Mental-Health-Social-Media-Analysis

**Project Overview**

This project explores the relationship between social media usage, sleep patterns, academic performance and mental health indicators among teenagers.

Using exploratory data analysis (EDA), I investigate patterns and potential associations between daily social media usage and factors such as stress, anxiety, depression labels, sleep duration and physical activity.

The project combines SQL-based data exploration with interactive visualisation to transform raw data into meaningful insights.

Project Objectives

The main objectives are to:

- Explore social media usage patterns among teenagers.

- Examine the relationship between daily social media usage and sleep duration.

- Investigate patterns in stress and anxiety levels across different social media usage groups.

- Explore how social media usage relates to academic performance and physical activity.

- Examine the distribution of depression labels across different usage groups.

- Communicate findings through an interactive analytics dashboard.

**Tools & Technologies**
- Databricks SQL: Data exploration, aggregation and analysis.

- Python: Planned additional analysis and visualisation.

**Analytical Approach**
The project follows an exploratory data analysis workflow:

1. Data Understanding: Examining the dataset structure, variables and distributions.

2. Data Quality Assessment: Checking for missing values, duplicates and potential data inconsistencies.

3. Univariate Analysis: Exploring individual variable distributions.

4. Bivariate Analysis: Investigating relationships between social media usage and selected lifestyle, academic and mental health indicators.

5. Group Analysis: Comparing outcomes across social media usage categories and demographic groups.

6. Correlation Analysis: Exploring linear associations between selected numerical variables.

7. Data Visualisation: Presenting key patterns through an interactive dashboard.

Social media usage is grouped into three categories for selected comparisons:

Low: Less than 2 hours per day.

Moderate: 2 to less than 4 hours per day.

High: 4 or more hours per day.


**Key Questions**

This analysis aims to explore questions such as:

- Which social media platforms are most commonly used?

- How does sleep duration vary across social media usage groups?

- Are higher social media usage levels associated with different stress and anxiety patterns?

- How are depression labels distributed across usage groups?

- Is there a relationship between daily social media usage and academic performance?

- What associations exist between social media usage and sleep duration?
